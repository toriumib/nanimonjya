Description

Short (one sentence)

A face-and-name memory training app backed by cognitive science — match face cards with name cards, practice with real people you know, and never freeze on a name again.

Medium (one paragraph)

PetaName helps you connect faces to names — the single most awkward memory failure in daily life. It combines a card-matching game with proven memory techniques: elaborative encoding, the Baker-Baker technique, self-referential processing, and spaced retrieval. Five modes cover different needs: Name Call (rapid name recall game), Face Memo (build avatars and log real people), Business Recall (simulate meeting → delay → recall), Project Noah (a sci-fi story mode), and a library of 25+ research-backed articles on name memory.

What makes it different

Most brain training games use abstract patterns. PetaName trains on faces and names — the specific thing people struggle with in real life. You can upload photos of actual colleagues or classmates and the app builds games around them. Every mechanic (deliberate delay, next-day review, recall-over-recognition) is grounded in published memory research, with citations provided in-app.
