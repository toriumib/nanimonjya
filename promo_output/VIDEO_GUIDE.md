# PetaName プロモーション動画 撮影&投稿ガイド

## 録画方法（所要3分）

### Windows Game Bar
1. Chrome/Edgeで https://web-sigma-drab-72.vercel.app を開く
2. **Win + Alt + R** で録画開始
3. 以下を順に操作:
   - ホーム画面5秒（ななちゃん・はなちゃんのアニメーション）
   - タブ切替で各機能を見せる（各3秒）
   - なまえコールの対戦を1回やる（15秒）
   - ショップでキャラクター一覧をスクロール（5秒）
   - ものがたり画面（3秒）
4. **Win + Alt + R** で停止
5. 出力: `C:\Users\tori\Videos\Captures\` ← デスクトップはこのフォルダ

### より良い画質が必要なら
- **OBS Studio**: `winget install OBSProject.OBSStudio`
- Window Capture → ブラウザ → Transformで9:16にクロップ（TikTok向け）

## 動画1: なまえコール対戦デモ（30秒）

### 撮るシーン
1. ホーム画面 → みんなでボタンを押す（3秒）
2. 人数選択（2人）を選ぶ（2秒）
3. 名前をつけるシーン（5秒）
4. 顔が出て名前を当てるシーン（10秒）
5. 結果発表 → 獲得枚数（5秒）
6. 最後にURLオーバーレイ「web-sigma-drab-72.vercel.app」（5秒）
