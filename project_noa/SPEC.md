## 1. プロジェクト概要

- **タイトル**: PROJECT NOA — 東戸塚・49光年の約束
- **ジャンル**: 記憶記録型ADV（ビジュアルノベル）
- **コンセプト**: 「覚えること」そのものがゲームプレイ。技術的ブレイクスルーはすべて個人的な記憶から生まれる。
- **設計思想**:
  - Simple story, complex characters.
  - 「好きだから覚えている」ではなく「**覚えているから会える**」。
  - 本作に悪役・裏切り・絶望エンドはない。どのエンドも全員生存のハッピーエンド。
- **物語骨子**: 約76億年後、赤色巨星に呑まれる直前の地球。最後のドームに残る17人。世代船NOA-1で48.9光年先のLHS 1140 bへ。「28年眠って2年起きる」を11回繰り返す330年の旅。プレイヤーは記録官（呼名官）として、全員の顔・名前・詳細を覚え続ける。
- シナリオ本文・キャラクター・科学考証は別ファイル `STORY.md` を正とする。本書は**エンジンとシステム**を定義する。

## 2. 技術スタック（Flutter）

- フレームワーク: **Flutter（Dart 3.x）**
- 状態管理: **Riverpod**
- 音声: `audioplayers`（BGMループ・SE・フェード）
- 永続化:
  - コンフィグ・システムデータ: `shared_preferences`
  - セーブデータ: `path_provider` + JSONファイル（スロット単位）
- シナリオ: JSON（assets、第6章フォーマット）
- テスト: `flutter_test`
- Lint: `flutter_lints`

## 4. NOA固有システム

### 4.1 キャラクターデータ (NoahField)
```dart
class NoahField {
  final String name;        // 名前（フルネーム）
  final String affiliation; // 所属
  final String hobby;       // 趣味
  final String commId;      // 通信ID（電話・メール）
  final String school;      // 学生時代
}
```
`assets/characters.json` に科学者16人＋土倉源三＝**17人分**を定義する。

### 4.2 記憶テスト（3択）
- 冷凍睡眠後の再会時に、NoahFieldのいずれかの項目を出題。
- **3択は「正解1＋“別のキャラクターの実データ”2」で自動生成**（ランダムダミー禁止）。
- 正解: `(キャラ, 項目)` ペアを記録。好感度小幅上昇。デートフラグ解禁の可能性。
- 誤答: 汚染ペアとして記録（バックログ汚染・演出に使用）。**ペナルティ減点はない**（本作は罰ではなく帰結を描く）。

### 4.3 記憶率（スコア）
- `記憶率 = 正解した(キャラ,項目)の数 ÷ 出しうる組の総数`。UIには百分率で表示（例 `43.75%`）。
- しきい値:
  - 過去一度でも **60%以上** → 3周目で「船内の謎 全解禁」
  - **100%** → 真ルート解禁（転送権の選択肢が出現）
- 最大到達値は**システムデータ側**に保存。セーブ/ロードでは改変不可。

### 4.4 好感度 (♥)
- 記憶と完全分離。**エンドの相手決定にのみ使用**。記憶率には効かない。
- デートイベント、詳細記憶（電話・メール・家族・学生時代）で上昇。

### 4.5 バックログ汚染（クロス・コンタミネーション）
- バックログは**正典テキストを保持**したまま、描画時のみ汚染を適用する。
- サイクル2以降、汚染レベルに応じた確率で、ログ内の**人名表記だけを別キャラの名前に差し替えて表示**（視覚演出）。
- 汚染率はサイクルごとに緩やかに上昇。「呼名の習慣」イベントで低下。
- 土倉源三の名は特別扱い: 第5覚醒期に「名前だけ欠落」する脚本イベント(4.7)を発火。

### 4.6 ルートロック（周回解禁）
| 周回 | 解禁 | 条件 |
|---|---|---|
| 1周目 | 4人ルート＋通常エンド3 | — |
| 2周目 | 残り4人のキャスト | 1周目クリア |
| 3周目 | 船内の謎 全解禁 | 記憶率の最大値 ≥ 60% |
| 真 | 転送権の使い道を選択可能 | 記憶率 100% |

### 4.7 脚本記憶イベント
- **第5覚醒期（145年目）**: 土倉源三の名だけ、選択肢にも入力にも現れない。船内DBはロック済み（演出）。各キャラからの「聞き込み」で回収。
- **最終（327年目）**: **3択なし。17人全員分のフルネーム入力**。名前入力UI（かな/漢字のゆるい正規化一致）をエンジンが提供する。

### 4.8 28年スキップと老化（環境ストーリーテリング）
- サイクル遷移時: フェードアウト → `agingLevel+1` → 背景バリアント切替（`bg_*_age0..10`）。
- 老化レベルに応じて BGM の加工（再生速度/フィルタ）、UIの風合い変化（ColorFilter）、背景オーバーレイへの小道具（落書き・忘れ物）追加。

## 6. シナリオスクリプトフォーマット (JSON)

`assets/scenes/` に1ファイル1シーン。

```jsonc
{
  "id": "act1_sc01",
  "chapter": "ACT I",
  "bg": "dome_office", "bgAge": 0,
  "bgm": { "id": "ambient_cooling", "fade": 1.5 },
  "lines": [
    { "t": "mono", "text": "ドームの朝は、鐘ではじまらない。" },
    { "t": "say", "name": "土倉", "sprite": "tsuchikura/normal", "text": "結論から言う。" },
    { "t": "fx", "kind": "shake" },
    { "t": "se", "id": "alarm" },
    { "t": "choice", "options": [
      { "text": "四名……？", "jump": "act1_sc01b" },
      { "text": "物理の限界、ということか", "jump": "act1_sc01c" } ] },
    { "t": "memtest", "char": "hibino", "field": "hobby" },
    { "t": "input", "kind": "name", "expect": "とくらげんぞう", "onSuccess": "act5_true" },
    { "t": "flag", "set": "saw_alarm_3rd" },
    { "t": "skip28y" },
    { "t": "jump", "to": "act1_sc02" }
  ]
}
```

ルール: テキストは `{w}`（ウェイト）とルビ記法をサポート。v1ではフラグ条件分岐は導入しない（エンジンを単純に保つ）。
