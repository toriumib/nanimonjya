==============================================================
LLM における Γ − C（探索的パイロット）
対象: Claude Code CLI (`claude -p`) / 対の数=16 / 各条件2反復
実施: 2026-08-15
==============================================================

【測定量】
  C = P(選択1 ≠ 選択2)   同一プロンプトの反復 = 応答の揺らぎ（ベースライン）
  P = P(予測1 ≠ 予測2)   自己モデル自体の揺らぎ（診断用）
  Γ = P(予測 ≠ 選択)     自己予測と実際の選択の乖離

--------------------------------------------------------------
【結果】
  C  選択の揺らぎ    8/16 = 0.500   95%CI [0.280, 0.720]
  P  予測の揺らぎ    4/16 = 0.250   95%CI [0.102, 0.495]
  Γ  予測 vs 選択    9/16 = 0.562   95%CI [0.332, 0.769]

--------------------------------------------------------------
【主仮説】 Γ − C = +0.062   95%CI [-0.256, +0.364]

  → 信頼区間が 0 を含む。**帰無結果。**
     自己予測を求めたことが、選択の分布を
     ベースラインの揺らぎを超えて変えたという証拠は得られなかった。

【副次観察】 C − P = +0.250   95%CI [-0.079, +0.515]

  → 信頼区間が 0 を含む。**主張できない。**
     ただし方向としては、選択(0.50)のほうが予測(0.25)より揺らいでいる。
     「何を選ぶと言うか」のほうが「実際に何を選ぶか」より安定している、
     という解釈が可能だが、n=16 では区別できない。追試の価値はある。

【位置バイアス診断】
  正規化後のA応答率 = 38/64 = 0.594
  → 左右のカウンターバランスは機能している（極端な位置固着はない）。
     0.5 からのズレは内容選好を反映していると解釈できる。

--------------------------------------------------------------
【⚠️ この結果の解釈上の限界 — 必ず併記すること】

1. **検出力が不足している。**
   n=16 では差の信頼区間の幅が約 ±0.31 である。すなわち本パイロットは
   **非常に大きな効果しか検出できない**。現実的な大きさ（0.1〜0.2）の
   効果があったとしても見逃す。ゆえにこの帰無結果は
   「効果がない」ではなく「大きな効果はなさそう」までしか言えない。
   差 0.20 の検出には各条件 200 試行程度を要する。

2. **測定対象は素のモデルではない。**
   Claude Code エージェント（システムプロンプト・ツール足場を含む）を
   測っている。「モデルの Γ − C」ではなく「その構成全体の Γ − C」である。

3. **温度を制御していない。**
   本設計は C をベースラインとして差し引くため温度制御を要さないが、
   温度固定条件との対比があればより強い。

4. **そもそも LLM は MacKay の検定になっていない。**
   LLM は呼び出し間に持続する状態をもたない。ゆえに Γ − C > 0 が
   得られたとしても、それは「予測が予測対象を変える」機構の証拠では
   ない。示せるのは「自己予測を求めたときの応答分布が、選択を求めた
   ときの応答分布と異なる」ことのみである。
   **人間の実験の代替にはならない。**

--------------------------------------------------------------
【この結果の価値】

主仮説は棄却されなかった（= 差は検出されなかった）。しかし本パイロットは
以下を確認した。

  ・測定パイプラインが動作し、解釈可能な数値と信頼区間を産出する
  ・ベースライン C を差し引く設計が、温度非制御下でも成立する
  ・位置バイアスのカウンターバランスが機能している
  ・必要な標本サイズが見積もれた（各条件 200 試行程度）

**測定器としては機能している。次は人間で、十分な検出力をもって走らせる。**
