# YouTube Shorts / TikTok 運用ガイド（SEO・アルゴリズム最適化）v2.3.0

前回の投稿が207再生だったため、**視聴維持率（Retention）**と**クリック率（CTR）**の
2点を軸に、動画構成とメタデータを設計し直したもの。

---

## 1. なぜ207再生で止まったのか（想定原因と対策）

| 想定原因 | 症状 | 対策 |
|---|---|---|
| 最初の1秒にフックがない | 冒頭でスワイプされ、維持率が落ちてインプレッションが伸びない | **0〜1.5秒に「顔写真＋この人の名前言える？」の問いを置く** |
| 静止画・無音の区間がある | 途中離脱ポイントになる | 動きのないカットは1秒以内にカット、常にテロップを出す |
| 得られる快感（ペイオフ）がない | 「見てよかった」が発生せず高評価・コメントに繋がらない | **正解の瞬間（○＋コイン獲得）を必ず入れる** |
| ループしない | Shortsは自動ループ。終端が冒頭に繋がらないと再生時間が伸びない | 最後を「で、この人だれだっけ？」で締め、冒頭の顔に戻す |
| コメント誘発がない | エンゲージメント率が低い | 「あなたは覚えられた？コメントで教えて」を入れる |

**アルゴリズム上の優先指標**: Shortsは「視聴維持率 → スワイプ率 → 高評価・コメント率」の順に効く。
まず1秒、次に完走、最後にエンゲージメント。

## 3. タイトル案（SEO＋CTR）

Shortsは**ブラウズ流入が主**なので共感型フックを前方に置きつつ、
検索キーワード（顔と名前／覚えられない／記憶術）も含めるハイブリッド型にする。

### 推奨（第1候補）
```
顔と名前が覚えられない人、これ試して【記憶トレアプリ】#Shorts
```
- 前方に検索キーワード「顔と名前」「覚えられない」
- 「これ試して」で好奇心ギャップ
- 全角32文字（スマホ表示で切れにくい）

### 代替案
```
名刺もらったのに名前が出てこない問題、解決した #Shorts
【記憶術】名刺の名前を一発で覚える方法 #Shorts
営業マン必見｜顔と名前を一致させる練習アプリ #Shorts
名前が出てこない…を無くす記憶トレーニング #Shorts
```

### タイトルNG
- ❌ 全部大文字・記号の連打（Playのメタデータポリシー同様、YouTubeでもスパム判定）
- ❌ 「神アプリ！！！」だけ（キーワードがなく検索に乗らない）

## 4. 概要欄（最初の2行が命）

「もっと見る」の前に表示されるのは**最初の約100文字**。ここにキーワードを凝縮する。

```
顔は覚えているのに、名前が出てこない。その悩みを解決するための記憶トレーニングアプリです。
名刺を渡されて自己紹介を聞き、少し時間をおいてから「この人だれだっけ？」を思い出す練習ができます。

▼ 何ができるアプリ？
・ビジネス特訓：名刺（会社名・肩書・連絡先）と顔をセットで覚える
・自分の名刺と顔写真を登録して、実際に会う人の予習・復習ができる
・みんなで対戦：1台のスマホで2〜4人、オンライン対戦にも対応
・記憶研究にもとづくコツ（テスト効果・分散学習など）を出典つきで解説

▼ こんな人に
・名刺交換した相手の名前をすぐ忘れてしまう
・営業、接客、イベントで人と会う機会が多い
・記憶術や脳トレに興味がある

▼ ダウンロード（無料）
Google Play：「名前を覚えよう」で検索
Web版（インストール不要）：https://web-sigma-drab-72.vercel.app

▼ 覚え方のコツ（動画内で使っている方法）
1. 出会う：顔・名前・会社名をセットで見る
2. 間をおく：すぐ確認せず、あえて忘れかける
3. 思い出す：見返さずに思い出す（テスト効果）

あなたは何人覚えられましたか？コメントで教えてください。

#Shorts #記憶術 #営業
```

### 概要欄のポイント
- 1行目に「顔」「名前」「覚え」のキーワードを自然に含める
- 箇条書きで機能を明示（Playのメタデータポリシーと同じ考え方＝正確に機能を伝える）
- 最後にコメント誘発の1文
- ハッシュタグは**概要欄の末尾に3個**（多すぎると評価が分散する）

---

## 5. ハッシュタグ戦略

### YouTube（3個に絞る）
```
#Shorts #記憶術 #営業
```
- `#Shorts` はShorts棚に載るため必須
- 残り2つは**競合が少なく意図が明確**なものを選ぶ

### TikTok（8〜12個、大小ミックス）
```
#名前を覚えよう #記憶術 #暗記 #営業 #ビジネススキル
#社会人1年目 #名刺交換 #アプリ紹介 #便利アプリ #脳トレ
```
- 大タグ（#アプリ紹介 #便利アプリ）でリーチ、小タグ（#名刺交換 #社会人1年目）で刺さる層に届ける

---

## 6. サムネイル（Shortsでも設定推奨）

- 顔写真を大きく＋白フチの太字で「この人の名前、言える？」
- 文字は**6〜10文字以内**（スマホの小さい表示で読める量）
- 背景はブランドカラー（#3A7BD5）で統一しチャンネルの一貫性を出す
