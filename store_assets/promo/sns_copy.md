## 動画の作り直し手順（再現用）

素材の撮影から書き出しまで、スクラッチのNodeスクリプトで完結する。

```bash
# 1) エミュレータで実プレイを録画（座標は1080x2400前提）
adb shell screenrecord --time-limit 58 --bit-rate 10000000 --size 720x1600 /sdcard/f3.mp4 &
adb shell input tap 540 1841   # 出会いに行く
adb shell input tap 547 2221   # つぎの人 / おぼえた（×4）
adb shell input tap 540 1762   # 思い出す
adb shell input tap 540 1225   # クイズ選択肢（1225/1396/1566/1737を循環させると正解を引きやすい）
adb pull /sdcard/f3.mp4

# 2) ナレーション音声を生成（PowerShell / Windows内蔵TTS）
#    ※ps1はASCIIのみ。日本語台本は外部UTF-8ファイルから読む
powershell -File tts2.ps1 -ScriptFile voice/script.txt -OutDir voice

# 3) フック／CTAカード＋動画を書き出し（sharp / ffmpeg-static）
node make_cards.js
node build_shorts.js
```

### ハマりどころ（次回のために）

- **画面録画は可変フレームレート**（画面変化が少ないと2fps台に落ちる）。
  キーフレームが疎で `-ss` の入力シークが数秒ずれるため、
  **先に30fps固定へ再エンコードしてから切り出す**こと。
- 操作中に `KEYCODE_BACK` を使うとアプリを抜けてPlayストアが前面に出る。**タブのタップで移動する**。
- アプリ起動直後はフレーム落ちでタップが効かないことがある。**起動後7秒ほど待つ**。
- ボタン座標は `adb shell uiautomator dump /sdcard/ui.xml` の bounds から取得できる。
- ffmpegの `drawtext` は中点「・」が字形によって化けることがある。テロップでは避ける。
- 結果画面のあとに**インタースティシャル広告が出る**（3プレイに1回）。素材にはその手前までを使う。
