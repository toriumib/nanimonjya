§2. なぜこうなるのか — 仕組み

5ステップで理解する

「AとB、どっちにしよう？」

↓

「たぶんAを選ぶ」← 考える前の状態から予測
↓

「やっぱりB！」← 考えた後の状態から選択

乱数ゼロ。完全に決定論的。なのに予測不能。

核心: 不動点方程式

f(s) = g( s ⊕ trace( σ(s) ) ) σ(s): 自己シミュレーション（「私はどうするだろう？」） trace(σ): その痕跡（脳の状態に刻まれる変化） ⊕: 状態の更新 σ は f 自身を呼び出す → 不動点方程式: f(s) = g( s ⊕ trace( f( s ⊕ trace( f( s ⊕ ... )))))

この方程式に閉じた解は存在しません。解くには実際にイテレーション（反復）するしかない。そのイテレーションが「選択する」という行為そのもの。
