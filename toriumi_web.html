§2. なぜこうなるのか — アーキテクチャ

核心原理

prediction = f( state_before ) ← 同じ決定関数 f choice = f( state_after ) ← 同じ決定関数 f f は固定された重み（人格・記憶・価値観）を持つ。 f は関係ある情報だけを選択的に読む（選択的注意）。 自己シミュレーションが f の「途中の思考」をログに刻む。 f はその「途中の思考」を読む → フィードバックループ → Γ>0。

5ステップ

① 選択を迫られる。「AかBか」

② 自己シミュレーション開始。f が現在の状態で「Aかな？」と評価 → その評価をログに刻む

③ 予測: f(before)。自己シミュレーション前の状態から判断

④ 選択: f(after)。自己シミュレーション後の状態（=②の痕跡を含む）から判断

⑤ Γ>0: ②の痕跡が f(after) の判断を変えた → 予測≠選択

なぜ対照実験が重要なのか

旧理論では SHA-256 の雪崩効果に頼っていた。どんなバイト列を追記しても Γ≈0.5 になった。

新理論では f が「関係ある情報」と「ノイズ」を区別する。自己の過去の出力は関係ある。無関係な文字列は無視する。

だから自己参照だけが Γ>0 を生み、パディングは Γ=0 になる。

これが査読を突破した決定的な改善点。
