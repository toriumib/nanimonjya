# PROJECT NOA — 東戸塚・49光年の約束

ゲーム企画のための創作設定サイト（静的HTML）。なまえがお本体（Flutterアプリ）とは独立していて、ビルドにも配信にも影響しない。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | 序章。世界設定、LHS 1140 b、発射場（大池町）の根拠 |
| `story.html` | 本編。五幕構成＋幕間「船内の小さな謎」（answerは `<details>` で伏せてある） |
| `characters.html` | 八人の科学者。担当技術／止まっている場所／過去のやり直し／個別ルートの結末 |
| `world.html` | 箱舟NOA-1の構造、航行年表、五百年テラフォーミング、用語集、参考文献 |
| `endings.html` | 四つのハッピーエンド、記憶テストの仕様、設計思想 |
| `assets/style.css` | 共通スタイル（ダーク＋明朝、レスポンシブ） |
| `assets/main.js` | 読書プログレスバー、ナビのアクティブ表示 |

## ローカルで見る

```sh
cd site/project-noa
python3 -m http.server 8080
# → http://localhost:8080
```

## デプロイ

このディレクトリをそのまま静的サイトとしてVercelに置いている（ビルド不要）。
`vercel.json` は不要（フレームワークなしの静的配信）。

## 注意

- 物語・人物・年代・組織はすべてフィクション。
- `world.html` の参考文献は企画時の参照メモ。販促物などに転記する場合は原典を確認すること。
